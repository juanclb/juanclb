---

Construo apps Android e iOS de ponta a ponta: do layout ao build nas lojas, passando por analytics,
notificações e monetização. Trabalho principalmente com React Native e Expo em TypeScript e, quando o
app precisa, escrevo o backend e o site também.

## O que eu construo

- **Apps de utilidade pública** — consulta de benefícios sociais e serviços para o cidadão, em produção,
  com Firebase (Analytics, Crashlytics, push) e anúncios.
- **Fitness** — um app de treino local-first (Expo Router, Zustand, NativeWind, gráficos em SVG) e um
  app de treino com API própria (Express + Prisma + MariaDB).
- **Web** — sites em Next.js + Tailwind publicados na Cloudflare Pages.
