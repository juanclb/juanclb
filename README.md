Oi! Sou o Juan e trabalho com desenvolvimento de apps para Android e iOS, hoje principalmente com
React Native e Expo em TypeScript. Costumo cuidar do app inteiro, das telas até a publicação nas
lojas, e quando o projeto precisa eu faço a API ou o site também.

### No que tenho trabalhado

- Apps de consulta de benefícios sociais, publicados na Play Store e na App Store
- Um app de treino que funciona offline, feito com Expo Router, Zustand e NativeWind
- Outro app de treino, com API própria em Express e Prisma
- Sites em Next.js com Tailwind, hospedados na Cloudflare
